ФОРМА «ДОДАЙ СВІЙ ДЕНЬ НАРОДЖЕННЯ» — ИНСТРУКЦИЯ ПО НАСТРОЙКЕ
===========================================================

КАК ЭТО РАБОТАЕТ
  Человек сканирует QR на экране -> открывается страница birthday.html (GitHub Pages)
  -> вводит ФИО, дату, фото -> данные уходят в скрипт Google (Code.gs)
  -> скрипт проверяет их и шлёт сообщение с фото в Telegram-группу админов
  -> админ проверяет и сам вносит запись в базу.
  На экран ничего не попадает автоматически.

ФАЙЛЫ
  birthday.html  - страница с формой (публичная, кладётся на GitHub)
  Code.gs        - скрипт-приёмник (остаётся ТОЛЬКО в Google Apps Script, на GitHub не загружать!)

------------------------------------------------------------
ШАГ 1. TELEGRAM-БОТ И ГРУППА
------------------------------------------------------------
 1. В Telegram откройте @BotFather -> /newbot -> задайте имя и username бота.
    Он выдаст ТОКЕН (длинная строка). Никому его не показывайте.
    Если токен засветился: @BotFather -> /revoke.
 2. Создайте отдельную группу для заявок (лучше закрытую, только админы)
    и добавьте в неё бота.
 3. Узнайте CHAT_ID группы:
      - в группе отправьте сообщение:  /start@username_вашего_бота
      - в браузере откройте:  https://api.telegram.org/botВАШ_ТОКЕН/getUpdates
      - найдите  "chat":{"id":-100xxxxxxxxxx ...}  - это число (с минусом) и есть CHAT_ID.

------------------------------------------------------------
ШАГ 2. GOOGLE APPS SCRIPT
------------------------------------------------------------
 1. Откройте script.google.com -> Новый проект (отдельный от «База даних»).
 2. Удалите всё в Code.gs и вставьте содержимое файла Code.gs из этой папки.
 3. Слева шестерёнка «Настройки проекта» -> «Свойства скрипта» -> добавьте:
      BOT_TOKEN    = токен от BotFather
      CHAT_ID      = id группы (например -1001234567890)
      TOPIC_ID     = (только если в группе включены «темы») id темы
      ACCESS_CODE  = (необязательно) «кодовое слово», см. ниже
 4. Вверху выберите функцию testTelegram -> «Выполнить» -> дайте разрешения.
    В группе должно появиться: «✅ Приймач заявок підключено».
 5. «Развернуть» -> «Новое развертывание» -> тип «Веб-приложение»:
      Выполнять от имени: Я
      У кого есть доступ: Все
    Скопируйте адрес веб-приложения (заканчивается на /exec).
 ВАЖНО: после ЛЮБОЙ правки Code.gs нужно сделать
    «Развернуть» -> «Управление развертываниями» -> карандаш -> «Новая версия».

------------------------------------------------------------
ШАГ 3. ВСТАВИТЬ АДРЕС В ФОРМУ
------------------------------------------------------------
 Откройте birthday.html в Блокноте, найдите в начале скрипта:
     ENDPOINT: 'PASTE_APPS_SCRIPT_URL_HERE',
 и вставьте адрес /exec между кавычками. Сохраните.

 Кодовое слово (необязательно): поставьте ASK_CODE: true в birthday.html
 и задайте то же слово в ACCESS_CODE в свойствах скрипта.
 Слово оглашайте голосом на служении.

------------------------------------------------------------
ШАГ 4. ВЫЛОЖИТЬ НА GITHUB PAGES
------------------------------------------------------------
 Старый QR вёл на:
    https://christian-word.github.io/slider/birthday/birthday.html
 Если репозиторий slider ваш и Pages включены - загрузите birthday.html в папку
 birthday этого репозитория (Add file -> Upload files). Адрес останется тем же,
 QR в слайдере заработает без изменений.
 Если адрес другой - впишите его в birthday_slider_qwen.html, строка QR_URL в блоке CONFIG.

------------------------------------------------------------
ШАГ 5. ПРОВЕРКА
------------------------------------------------------------
 Откройте страницу с телефона, отправьте тестовую заявку.
 В группе должно прийти сообщение с фото и данными.
 Если форма пишет «Немає зв'язку з сервером»:
   - проверьте, что вставлен адрес, заканчивающийся на /exec;
   - доступ развертывания = «Все»;
   - после правок скрипта сделана «Новая версия».

------------------------------------------------------------
ЗАЩИТА (ЧТО БУДЕТ, ЕСЛИ QR УЗНАЕТ ЗЛОЙ СОСЕД)
------------------------------------------------------------
 - Заявка не меняет базу: худший случай - мусорное сообщение в группе админов.
 - Токен бота не лежит на сайте, он только в Script properties.
 - Лимиты: не более 20 заявок в час и ~50 за 6 часов на всех; потом форма просит подождать.
 - Скрытое поле-ловушка для ботов, минимальное время заполнения, проверка полей и JPEG.
 - Кодовое слово (по желанию) + блокировка перебора слова.
 - Если нужно срочно остановить приём: Apps Script -> Управление развертываниями -> архивировать
   (или @BotFather -> /revoke токена).
